Introduction

Mina Kimes is an ESPN NFL analyst. I want to find out whether her football predictions are significantly better than her peers. I am using her podcast, The Mina Kimes Show featuring Lenny, as the primary source for predictions about the 2024 National Football League season and the 2025 FTN Football Almanac as my source of truth.

I will compare the predictions she made about the best offensive and defensive teams of the 2024-2025 National Football League seasons to her peers which she invited to make the same picks on her podcast episodes: “Goff We Go: Picking the Top 10 Offenses of 2024” and “Jets Get It On: Ranking the Top Defenses of 2024”.

Reorient data into columns

I have converted every row in my table into a list in Python. Count the number of picks per analyst

My first step in analyzing data is to characterize it by generating basic summary statistics. Looking at the first (2) rows of my table which include a header row as well as a single row of data, I can see that some rows have information represented as categories and some as numbers. This is a valuable distinction because I will need different methods to summarize numerical and categorical data. Numbers are easy to summarize because I can use standard mathematical algorithms like summing and counting. In the case of categorical data, the mathematical relationships between categories are not obvious. However, one thing that I can do is to count the number of occurrences of each category.

How do I know which columns contain what kind of data?

In order to design a robust system of analysis, I want to make my analytical framework as generalizeable as possible. This means minimalizing the amount of assumptions I make about my data. To understand the type of data present in each of my columns I can use a list comprehension with the isinstance() function in order to get a list of the data type (string, integer, float, etc.) of each item in that column which I have represented in Python using a list. I can then convert that list of types into a set, which is a special type of list, so that I only retain unique values of the original list. This set will include all of the types of data present in my column. And because each type will only be present once in the set, I can count the length of the set to find out how many data types are present. If all of the data types are numerical, then I can apply mathematical algorithms to understand that column. If the column contains numerical and categorical data then I can treat that data as categorical since I do not have a method to naively predict how to map categorial data to numerical values.

A note on list comprehensions

List comprehensions follow the general syntax of “do this for each of these in those”. For example, calculate the length of this string for each string in those strings where a string is a string of characters.
