Introduction

I want to develop a database of football players that is keyword searchable as a standard search engine is. My intention is to store words in a central index file and represent the data structure using metadata stored in a series of JSON formatted lists with references to the index.

I am organizing this as a columnar database so that all of the values of a particular category such as “position” are all stored in the same file. Where do I start? First I need to understand all of the files in my database. I can organize them all into a directory named “database”.

I intend to store all of my database files in JSON format and code everything in the Python programming language.

I can code the paths to all of my database files directly into my code for now and worry about how to load them more systematically in the future. I can use a dictionary to define the structure of my database.

def source_traversal_search(source_path, sources_to_look_for, sources_traversed=[]):
    # Add the current file to the list of files traversed
    sources_traversed.append(source_path)    

    # Check if the current file is the one that I am looking for
    #sources_to_look_for = [location["source"] for location in locations_to_look_for]
    if source_path in sources_to_look_for:
        return sources_traversed

    with open(source_path, 'r') as source_handle:
        source_data = json.load(source_handle)
    next_source = source_data[-1]
 
    if next_source in sources_to_look_for:
        sources_traversed.append(next_source)
        return sources_traversed
    else:
        return source_traversal_search(next_source, sources_to_look_for, sources_traversed)
