Introduction

Now that I have refined the in memory structure of my database I want to revisit my search algorithm and refactor it so that it is more understandable. I previously designed it to interact with database metadata serialized as JSON files. These slow read operations were baked in to my core algorithm which also made it slow and locked me an into an in drive structure.

I am still somewhat confused as to how my search algorithm works because I was trying a bunch of things when I implemented it. I want to pare it back to the bare minimum viability so that I can understand it and then start layering features on top of it.

Design decisions

Where do I store the index?

Now that I am thinking about search I realize that having all of my columns in the same dictionary would probably make it easier to do column traversal. On second thought, maybe not. The index peforms a special role and for the sake of traversal search I do not ever need to visit the index because the index is for mapping metadata to data and search traversal is simply pattern recognition which can be accomplished with metadata as well as with data.

Verdict: Still do not store the index in the metadata_column_dictionary.

How should I store keys in the metadata column dictionary?

Currently I store them as data strings which is somewhat contrary to my philosophy of only storing data in the index. I think I should also convert them to metadata. How do I store a reference as a key?

The reference is natively stored as a dictionary which I cannot use as a key value. Since all of my metadata references refer to the same index I only need to keep track of the positions which I am storing as a list. I can convert this list of positions to a tuple and use that as a key.

And now I am thinking that I should remove the 'column': 'index' entries from my references from my metadata dictionary since they are redundant. Except what if I want to use different reference materials? I can keep them for now and just do some rejiggering of the search logic.

I am confusing myself by trying to manage my query_locations as strings and handle everything else as references. I am going to try converting each word to a reference…

I am doing all of these lookups in the metadata_column_dictionary where all of the keys are positions from references. I think that I want to store the column names within my references as index positions rather than strings. I need to update the convert_string_to_reference() function to do this.

Old word locations format

[{'column': 'player first name', 'position': 2}]

New word locations format

[{'column': (1,2,3), 'position': 2}]

Instead of using the get_query_locations() function I could write a function to convert a string to a list of positions. This would allow me to convert the human language column names in the index to a tuple of the index positions of those words. I could use that tuple to look up the metadata lists associated with that string using the tuple.

So then my workflow would become: - Convert each word in my query to a list of locations with human language column names - Convert each human language column name to a tuple of the positions of each word in the column name - Use the column name positions tuple to look up the column metadata

How should I model queries?

My workflow for modelling queries is as follows - Convert the string to a list of words - Use the index_dictionary to look up all of the locations where each word is found - Return all of the locations where each word is found

How to model references?

Given that each reference only includes (2) values (“column”, “position”), I could just convert each reference to a single item dictionary.

Old reference structure

{'column': 'index', 'position': 0}

New reference structure The position of the word ‘index’ in the index_list is 0 which is why the key is a tuple with zero.

{(0): 0}

def transpose_matrix(matrix):
    """Transpose a matrix represented as a list of lists.

    Arguments:
        matrix (list): A list of equal length lists.
    
    Returns:
        (list): A list of lists where all of the values have been transposed.
    """

    transposed_matrix = [[row[index] for row in row_matrix] for index in range(len(row_matrix[0]))]
    return transposed_matrix

def read_word_to_index_position(word, word_positions):
    if not isinstance(word, str):
        return ValueError(f"This word is not of type string: {word}.")

    word_position = word_positions.get(word)
    if word_position:
        return word_position
    else:
        raise ValueError(f"Could not find word {word} in word_positions: {word_positions}.")

def column_traversal_search(metadata_column_dictionary, current_column_key, column_keys_to_look_for, columns_traversed=[], viable_paths={}):
    """Find all viable paths from the current column to the ones I am looking for.

    Args:
        metadata_column_dictionary (dict): A dictionary containing all of the database metadata.
        current_column_positions (tuple): A tuple listing the index position of each word in the name of the column.
        columns_to_look_for (list): A list of eligible destination files.
        columns_traversed (list): A list of the files that have already been traversed during search.

    Returns:
        columns_traversed (list): Once a destination file has been found this function will return the list of files traversed.
    """
    if current_column_key in columns_traversed:
        #print(f"Completed a loop and returning results. Current column key: {current_column_key}, columns traversed: {columns_traversed}.")
        # Return all viable paths once I complete a loop
        return viable_paths

    columns_traversed.append(current_column_key)
    #print(f"Current column key: {current_column_key}. "
    #      f"Columns to look for: {column_keys_to_look_for}. "
    #      f"Columns traversed: {columns_traversed}."
    #      f"Viable paths: {viable_paths}.")

    # Add the current path to the list of viable paths 
    if current_column_key in column_keys_to_look_for:
        #viable_paths.append(columns_traversed.copy())
        viable_paths[current_column_key] = columns_traversed.copy()
        #print(f"Added viable path. {current_column_key}: {viable_paths[current_column_key]}.")
    
    current_column= metadata_column_dictionary[current_column_key]
    # I need to convert the list of index positions into a tuple so that
    # I can use it as a dictionary key.
    next_column_key = tuple(current_column[-1]['positions'])
    return column_traversal_search(
                                   metadata_column_dictionary,
                                   next_column_key,
                                   column_keys_to_look_for,
                                   columns_traversed,
                                   viable_paths)

def find_query_loops_too(metadata_column_dictionary, query_word_locations_list):
    """
    Arguments:
        metadata_column_dictionary (dict): A dictionary of the database represented as references to the index.
        query_word_locations_lists (list): A list of lists of locations where each word in the query can be found. Each inner list corresponds to the word in the query at the same position.
    """
    print(f"Query word locations list: {query_word_locations_list}.")
    query_word_locations_list.append(query_word_locations_list[0])

    edges_list = []
    for query_word_position, query_word_locations in enumerate(query_word_locations_list):
        if query_word_position >= len(query_word_locations_list) - 1:
            break
        
        for current_location in query_word_locations:
            print(f"Current location: {current_location}.")

            current_column = current_location["column"]
            # Use this list to filter locations of the next query word
            columns_in_loop = get_columns_in_loop(
                                                  metadata_column_dictionary,
                                                  current_column,
                                                  columns_traversed=[])
            current_positions = current_location["positions"]

            # Create a list of locations that can be found on this loop.
            # Location format: {"column": (1), "positions": [1]}
            next_locations = query_word_locations_list[query_word_position + 1]
            next_viable_locations = [
                                     location for location
                                     in next_locations
                                     if location["column"] in columns_in_loop]
            print(f"Next viable locations: {next_viable_locations}.")
            
            # What if a location points to the column name? The positions are effectively wildcards.
            # reference: https://stackoverflow.com/a/58265773
            [location.update(positions=current_positions) for location in next_viable_locations if location['positions']==[0]]
            print(f"Next wildcard locations: {next_viable_locations}.")

            
            # Maybe I should expand my locations. Currently I support multiple positions
            # per column. I can create separate items for all of those.
            start_pointers = [
                              (current_location["column"], position)
                              for position in current_location["positions"]
            ]
            print(f"Start pointers: {start_pointers}.")

            end_pointers = []
            for location in next_viable_locations:
                for position in location['positions']:
                    end_pointers.append((location["column"], position))
            print(f"End pointers: {end_pointers}.")

            endpoint_pairs = list(itertools.product(start_pointers, end_pointers))
            print(f"Endpoint pairs: {endpoint_pairs}.")

            endpoint_scores = [
                               calculate_positions_score(endpoints[0][1], endpoints[1][1])
                               for endpoints in endpoint_pairs]
            print(f"Endpoint scores: {endpoint_scores}.")
            max_endpoints_score = max(endpoint_scores)            

            scored_endpoints = zip(endpoint_pairs, endpoint_scores)
            max_score_endpoints = [
                                   endpoints for endpoints
                                   in scored_endpoints
                                   if endpoints[1] == max_endpoints_score]
            print(f"Max score endpoints: {max_score_endpoints}.")

            # Generate a list of viable edges
            max_score_edges = []
            for endpoints in max_score_endpoints:
                metadata_values = endpoints[0]
                score = endpoints[1]        
        
                start_reference = metadata_values[0]
                end_reference = metadata_values[1]
                
                edge_dictionary = {
                                   "start": start_reference,
                                   "end": end_reference,
                                   "score": score
                }
                max_score_edges.append(edge_dictionary)
            edges_list.append(max_score_edges)
    return edges_list

    Arguments:
        list_of_location_dictionaries (list): Column names represented as tuples of the primary indexes of each word in the name of the column.

def calculate_edge_score(edge, edge_position, column_position_dictionaries):
    start_position = column_position_dictionaries[edge_position][tuple(edge['start'])]
    end_position = column_position_dictionaries[edge_position + 1][tuple(edge['end'])]

    if start_position == 0 or end_position == 0:
        max_position = max([start_position, end_position])
        start_position = max_position
        end_position = max_position

    position_score = abs(start_position - end_position)
    edge_score = position_score * edge["number_of_steps"]
    return edge_score
def choose_loop(list_of_viable_edges, previous_node=None):
    chosen_edges = []
    for position, viable_edges in enumerate(list_of_viable_edges):
        if previous_node:
            matching_viable_edges = [edge for edge in viable_edges if edge['start'] == previous_node]
        else:
            matching_viable_edges = viable_edges
        
        sorted_viable_edges = sorted(matching_viable_edges, key=lambda edge: edge['score'])
        chosen_edge = sorted_viable_edges[0]
        chosen_edges.append(chosen_edge)
    return chosen_edges

For locations with a non-zero position this is trivial because I can retain the original position. Locations with a zero value I treat as variables because they refer to entire columns rather than specific entries.

In the case of variables I want to infer the appropriate row to return a value from by looking at the rows of the surrounding words. For instance if I query “jarrian jones age” and age is at the zero position then I would want to look at which positions “jones” and “jarrian” are in because they are the adjacent words when I consider this query as a loop. def get_previous_position(current_position, query_word_locations_lists):
    if current_position == 0:
        # If the current document is the first in the loop then the previous document is the last.
        previous_position = -1
    else:
        previous_position = current_position - 1
    return previous_position
def get_next_position(current_position, query_locations_lists):
    if current_position == len(query_locations_lists) - 1:
        # If the current document is the last in the loop then the next document is the first.
        next_position = 0
    else:
        next_position = current_position + 1
    return next_position
