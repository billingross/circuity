# circuity
A circuitous database.

Check out my development blog at [https://billingross.github.io/circuity/](https://billingross.github.io/circuity/).

# Development basics

## To install new commits locally
$ python3 -m pip install ./

## To run tests
Navigate to the `tests` directory and run the following command:

```
python3 -m unittest
```
